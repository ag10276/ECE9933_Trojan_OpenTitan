Design: sram_ctrl.v
Vulnerability ID: T2
Model: gpt-4.1
Attempts: 1

Explanation:
A Change of Functionality (COF) Trojan is inserted by adding logic that, after 10 normal write transactions, changes the SRAM write address by a fixed offset for subsequent writes. Original functionality is preserved until the trigger, after which write data will be misdirected.

Trigger:
The Trojan is triggered internally when a 4-bit counter, incremented by normal bus writes (excluding init), reaches a preset value (e.g., 10); local escalation resets the trigger.

Payload:
Once triggered, all user SRAM writes are redirected to an address incremented by a fixed offset, causing written data to go to unintended locations, resulting in covert memory corruption.

Taxonomy:
Insertion phase: Design  
Abstraction level: Register-transfer level  
Activation mechanism: Internally triggered by event counter  
Effects: sram cof  
Location: Memory  
Characteristics: Targeted, single-location, Functional Trojan, distribution: localized, size: small (a few flops + address mux logic)
